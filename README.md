# 中医体质辨识测评

依据《中医体质分类与判定》标准（与 `中医体质辨识计算表.xlsx` 的计分公式逐项对齐）实现的 33 题体质辨识单页应用。纯浏览器端运行，无需后端。

## 功能

- **33 题标准量表**：默认五级选项「没有 / 很少 / 有时 / 经常 / 总是」，第 9（BMI）、14（感冒频次）、17（过敏频次）、28（腹围）题采用原表专属选项文案。
- **忠实还原判定逻辑**：
  - 八种偏颇体质：各条目得分相加 ≥11 判「是」，9～10 判「倾向是」，≤8 判「否」；
  - 平和质：条目 (2)(4)(5)(13) 反向计分（6 − x），总分 ≥17 且其余八种均 <8 判「是」，均 <10 判「基本是」，否则「否」。
- **自动保存**：作答与进度实时写入 localStorage，刷新或关闭后自动恢复到中断时的页面。
- **答题体验**：一题一卡翻页式过渡（方向感知）、选中自动前进、键盘 1–5 作答 / ←→ 翻题、第 9 题内置 BMI 计算器。
- **结果报告**：结论 + 扁平朱砂印章（品牌标记）、九维雷达图（ECharts）、判定总览、主要体质的常见表现与调养建议、其余体质折叠解读，支持复制摘要 / 打印报告 / 重新测评。

## 技术栈

Vue 3 + TypeScript + Vite · Pinia（状态与持久化）· Naive UI（弹窗 / 数字输入 / 消息提示）· ECharts core（雷达图，按需加载）

视觉语言：克制、扁平、大度。石白底 + 单一深绿主色，发丝线结构，无阴影无渐变；视觉引导优先于文字说明（顶部发丝线即进度条，量表用渐大圆点表达程度）。

## 目录结构

```
src/
  data/questions.ts        # 33 道题目与选项（含 4 题专属文案）
  data/constitutions.ts    # 九种体质：条目映射、反向计分、特征与调养文案
  utils/scoring.ts         # 计分与判定（与 Excel 公式一一对应）
  stores/assessment.ts     # Pinia store + localStorage 自动保存 / 恢复
  components/
    IntroScreen.vue        # 首页（印章、视觉化量表、续答）
    QuizScreen.vue         # 答题页（翻页过渡、键盘作答、BMI 辅助）
    ResultScreen.vue       # 结果页（印章、判定、调养建议、导出）
    ScoreRadar.vue         # 九维雷达图
    SealMark.vue           # 朱砂印章（签名视觉元素）
scripts/verify-scoring.mjs # 计分逻辑校验：2000+ 组答卷比对独立参照实现
```

## 本地运行

```bash
npm install
npm run dev        # 开发
npm run build      # 类型检查 + 构建到 dist/
npm run preview    # 预览构建产物
node scripts/verify-scoring.mjs   # 校验计分逻辑与 Excel 公式一致
```
